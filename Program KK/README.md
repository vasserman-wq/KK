# KK — единая программа карт контроля для SOLIDWORKS (без Excel)

Программа запускает макросы 1 и 2 в SOLIDWORKS и даёт редактировать карту в своём окне.
Excel больше не нужен: макросы получают от программы **эмулятор Excel**, который читает и пишет
обычные файлы `.xlsm`/`.xlsx`. Логика макросов (ключи баллонов, привязки, ручные данные,
защитные остановки) не переписана: в них меняются только точечные строки (см. ниже).

> **Важно.** Код проверен только статически и тестами без Windows. Сборка exe, запуск в Windows,
> компиляция VBA и работа в SOLIDWORKS **не выполнялись**. Первый прогон — только на копии
> чертежа и карты, по шагам из `docs/TESTING.md`.

## Состав

| Папка / файл | Назначение |
|---|---|
| `KK.py`, `kk/` | программа (Python 3.10+, tkinter) |
| `kk/xlshim/` | эмулятор Excel для макросов (COM-объект `KK.ExcelShim`) |
| `kk/card.py` | карта: блоки, вводные, нумерация, итоги, реквизиты (правила из `OK_IntroEditor`) |
| `kk/sw.py` | SOLIDWORKS: подключение, `RunMacro2`, список размеров и заметок, подсветка |
| `vba/KK_Bridge.bas` | новый модуль VBA: связь макросов с программой |
| `tools/patch_macros.py`, `patch_macros.bat` | вносит точечные правки в тексты макросов |
| `KK.spec`, `build.bat`, `requirements.txt` | сборка `KK.exe` |
| `tests/` | тесты (эмулятор и карта на примере КК D10ДМ.11.000 Рама) |
| `docs/` | архитектура, проверка в SOLIDWORKS, опись обращений к Excel |

## Установка и запуск — по шагам

### 1. Подготовка (один раз)
1. Установите Python 3.10 или новее с python.org (галочки «tcl/tk» и «py launcher» включены по умолчанию).
2. Распакуйте архив так, чтобы папка `KK` лежала в корне репозитория, рядом с
   `Настройки_ОК.xlsx`, `passport_macro` и текстами макросов.
3. В папке `KK` выполните: `py -m pip install -r requirements.txt`.

### 2. Правки в макросах (один раз на версию макросов)
1. Запустите `patch_macros.bat`. Он возьмёт `..\SOLIDWORKS_KC_v16.5.15_review (1).txt` и `..\2 Макрос (2).txt`
   и создаст в `vba\patched` файлы `*_KK.txt` (Windows-1251) и отчёты `*_KK.report.txt`.
   Если обязательное место не найдено ровно один раз, скрипт останавливается и ничего не пишет.
2. Сделайте копии своих `.swp` (например `1 Макрос KK.swp` и `2 Макрос KK.swp`).
3. В SOLIDWORKS: Инструменты → Макрос → Редактировать → копия макроса 1. В основном модуле:
   Ctrl+A, вставить текст `SOLIDWORKS_KC_v16.5.15_review (1)_KK.txt`. Затем File → Import File →
   `vba\KK_Bridge.bas`. Затем Debug → Compile. Сохранить.
4. То же для макроса 2 с `2 Макрос (2)_KK.txt` и тем же `KK_Bridge.bas`.
5. Рядом с `.swp` должен лежать `Настройки_ОК.xlsx` (как сейчас). Если его нет, программа
   создаст его из встроенных значений.

Что меняют правки (полный список строк — в отчёте):
- `CreateObject("Excel.Application")` → `KK_Excel(True)`, `GetObject(, "Excel.Application")` → `KK_Excel(False)`;
- именованные аргументы `Worksheets.Add(After:=)` и `Names.Add name:=, RefersTo:=` → позиционные (в Excel работали бы так же);
- макрос 1: режим из программы вместо InputBox (если команды нет — меню как раньше);
- макрос 1: решение «включать в карту» берётся из программы; если решения нет — по маркерам `#`/`@`
  как раньше. При решениях из программы маркеры в чертёж не ставятся и не снимаются.

### 3. Запуск из исходников (для проверки)
```
cd KK
py KK.py
```
Проверка без окна: `py KK.py --check`. Тесты: `py -m pytest -q tests`.

### 4. Сборка KK.exe
Запустите `build.bat`. Он копирует `Настройки_ОК.xlsx` и `passport_macro\assets\app.ico` в `kk\resources`,
ставит зависимости, гоняет тесты и собирает `dist\KK.exe` (один файл).
Общие пути к макросам для всех: положите рядом с `KK.exe` файл `kk_config.json`
(образец — `kk_config.example.json`). Личные пути задаются в программе: Сервис → Пути к макросам.

## Работа в программе
1. **Чертёж** — откройте чертёж в SOLIDWORKS и нажмите «Обновить из SOLIDWORKS».
   Карта — «<чертёж> — карта контроля.xlsm» рядом с чертежом (старые карты открываются как есть).
2. **Разметка** — «Прочитать чертёж», затем отметить «В карту / нет» (двойной щелчок или Пробел).
   Выбранная строка подсвечивается в SOLIDWORKS. «Сохранить разметку».
3. **Баллоны и карта** — «Запустить режим 1». На вопросы макроса отвечайте в окне SOLIDWORKS.
4. **Реквизиты и подписи** — номер КД, наименование, первичное применение, масса, оборудование, подписи, исполнения.
5. **Карта контроля** — первые три строки ОК1 и одна таблица пунктов. Двойной щелчок — текст,
   до 4 средств ТО из списка, объём, время. Итоги считаются автоматически. Номер баллона защищён.
   Добавление/удаление вводного пункта переводит карту в PENDING: после него снова выполните шаг 3.
6. **Листы ОК** — проверка готовности и «Запустить макрос 2».

Журнал программы: `%LOCALAPPDATA%\KK\kk.log`. Вызовы макросов, которые эмулятор не поддержал,
видны в Сервис → Журнал эмулятора Excel — присылайте его текст, если что-то остановилось.
